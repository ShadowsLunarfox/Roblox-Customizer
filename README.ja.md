<a id="installation"></a>

## 📦 インストール

[Chrome ウェブストア](https://chromewebstore.google.com/detail/roblox-customizer/docflecekjjcekdcapolmneiomimiboi)からインストールし、開いている Roblox のページを再読み込みしてください。

<details>
<summary><strong>Chrome または Edge にリポジトリを手動で読み込む</strong></summary>

1. このリポジトリをダウンロードまたはクローンします。ZIP の場合は展開してください。
2. `chrome://extensions` または `edge://extensions` を開き、**デベロッパーモード**を有効にします。
3. **パッケージ化されていない拡張機能を読み込む**を選び、`manifest.json` があるフォルダーを指定します。
4. Roblox を再読み込みします。

実行に必要なファイルはリポジトリに含まれているため、インストール時のビルドは不要です。拡張機能のフォルダーは固定の場所に保管してください。

手動更新ではファイルを置き換え、拡張機能の管理ページで**再読み込み**してから Roblox を再読み込みします。

</details>

初回アクセス時に利用規約への同意を求められます。同意はこのブラウザーに保存され、**すべてリセット**の後も保持されます。

初回のRobloxアクセス時に、言語と拡張機能の通知が終わるとガイドが自動表示されます。**Robloxの歯車 → Roblox Customizer**と**ブラウザーのツールバーにあるRoblox Customizerアイコン**の2つの入口を案内し、**設定を開く**ボタンも用意しています。更新のお知らせはガイドの後に表示され、どちらも先に設定を開く必要はありません。閉じた状態は個別に保存され、新しいお知らせIDではお知らせだけが再表示されます。

<a id="quick-start"></a>

## 🚀 はじめに

Roblox を開き、ブラウザーのツールバーにある拡張機能のアイコン、または Roblox の歯車メニューの **Roblox Customizer** を選びます。設定は自動保存されます。

| 設定カテゴリー | 管理できる内容 |
| --- | --- |
| **外観** | 背景ファイル、暗さ、すりガラスのぼかしと不透明度、透明効果、カスタムカラー、ウェブサイトのフォント。 |
| **ホーム** | ホームバナー、あいさつ、時計、フレンドの行数、おすすめ、プレイ時間、最近のサーバーの記録。 |
| **ピン留めしたゲーム** | ピン留め機能の有効・無効、保存済みゲームとフォルダー。 |
| **ソーシャル** | ゲーム、コミュニティ、プロフィールページごとの X・YouTube フィード。 |
| **通貨** | Robux の通貨換算の目安と表示通貨。 |
| **言語とデータ** | 拡張機能の言語、バックアップ、復元、リセット。 |

ゲームはゲームページの**ゲームをピン留め**からフォルダーを選んで保存できます。フレンドはプロフィールの**フレンドをピン留め**、またはホームや自分のフレンドページの**ピン留めしたフレンドを管理**から追加できます。

**ホーム → ホームのフレンド**で、**Roblox標準のフレンド一覧を表示**と**ピン留めしたフレンドを表示**を個別に切り替えられます。非表示にしても保存済みのピン留めは保持され、ページを再読み込みしても設定は維持されます。

**ホーム → ホームバナー**で**バナーの背景と枠線を表示**をオフにすると、外側のすりガラス背景と枠線だけを非表示にできます。アバター、あいさつ、時計、プレイ時間カードは表示されたままで、設定は自動保存されます。

<a id="features"></a>

## ✨ 機能

### 🎨 外観とホーム

- ローカルの画像、アニメーション GIF、MP4 動画を背景に設定し、表示方法と暗さを調整できます。
- すりガラスのぼかしと不透明度を調整し、ぼかしや透明効果を無効にできます。実験的な配色設定では文字色、背景色、アクセントカラーを選べます。
- 最大 32 MB の TTF、OTF、WOFF、WOFF2 フォントを読み込めます。プレビュー、一時無効化、標準フォントへの復元に対応し、含まれない文字には代替フォントを使います。
- ホームのあいさつと時計をカスタマイズできます。バナー、アバター、名前、あいさつ、時刻、日付、最も遊んだゲームのカードを個別に表示・非表示にできます。
- 標準のフレンド一覧を最大 3 行に展開し、ピン留めしたフレンドをホームにまとめ、ゲームをフォルダーで整理できます。
- お気に入り、注目のゲーム、おすすめの各セクションや、個別のおすすめゲームを非表示にできます。

### 👥 フレンドとフォロワー

フレンドツールは Roblox 標準のツールバーとカードに機能を追加します。アバター、メニュー、チャット、参加ボタン、ページ切り替えは標準のものを維持します。

- オンライン、ゲーム中、オフライン、Studio、ピン留め状態で絞り込めます。表示名、ユーザー名、オンライン優先、ピン留め優先で並べ替えられます。
- 標準カードのチェックボックスでユーザーを選択できます。ページを移動しても選択は保持され、現在のページや絞り込み結果全体を選べます。
- 選択したユーザーのフレンド解除やフォロー解除、フレンド申請の承認・無視をまとめて行えます。送信前に対象者を確認でき、進行状況と失敗結果を表示します。実行中の処理が終わった時点で後続処理を停止できます。
- プロフィール、標準のフレンド一覧、管理画面からピン留め・解除できます。このブラウザー内で Roblox アカウントごとに保存します。
- Roblox の件数 API が利用できる場合、標準のフォロワー見出しに `500+` ではなく実際の総数を表示します。

フレンド解除は Roblox 上の関係を変更し、拡張機能から取り消すことはできません。ピン留めはローカルのホーム一覧のみを変更します。

### 🎮 ゲームとサーバー

- ゲームページでバッジやゲームパスの詳細、プライベートサーバーカード、**ゲームメモ**を利用できます。
- プレイヤー数、満員ではないこと、国、都市、Ping で公開サーバーを検索できます。接続情報での並べ替え、シャッフル、ランダム参加、優先都市の代替選択にも対応します。
- 地球儀をドラッグ・拡大縮小し、国をクリックするか国名を検索して地域を選べます。
- データがある場合、サーバーのパフォーマンス、Roblox が報告する言語の一致人数、実行中のプレースのバージョンを表示します。言語の一致は Roblox のウェブサイト言語を基準とし、プレイヤーが実際に話す言語を確認するものではありません。
- 最近のサーバーへの再参加、利用可否の確認、ゲーム単位の履歴削除ができます。サブプレースへの訪問は所属ゲームにまとめられます。記録は**ホーム → 最近のサーバー**でプレイ時間とは別に設定します。

サーバーフィルターは再読み込みやページ移動でリセットされます。地域と件数は読み込んだデータに基づき、新旧順の並べ替えには信頼できる起動時刻が必要です。最近のサーバーの確認では最大 500 件の公開サーバーを調べ、結果が不完全なら不明のままにします。満員、終了、参加制限のあるサーバーには参加できない場合があります。

### 🧍 アバターとアニメーションプレビュー

- Roblox 標準の 3D プレビューと独立した 2D プレビューを並べて表示します。カテゴリーとアイテム一覧は画面サイズに合わせて配置されます。
- **自分のアバター**で**アバターツール**を開き、6 部位の RGB カラーや、対応する装着済みアクセサリーの位置・回転・拡大率を Roblox の許容範囲内で調整できます。
- 編集内容はローカルで確認し、**色を適用**または**アクセサリーに適用**を選ぶとログイン中のアバターに反映されます。標準プレビューの更新にはページを再読み込みしてください。
- アニメーションバンドル、単体アニメーション、エモートのページで**自分のアバターでプレビュー**を選ぶと、現在のアクセサリーを付けたアバターで動作を確認できます。標準の動作選択や再生操作と同期します。

アニメーションプレビューは R15 リグを使ってローカルで動作し、画面外やバックグラウンドのタブでは一時停止します。プレビューによって装着アイテムや保存済みコーデが変更されることはありません。

### 🧰 アイテム詳細とリソースエクスプローラー

- カタログ、バンドル、ライブラリ、Creator Store の標準の詳細欄に、ID、取得可能な日付、販売数などを補足します。既存の購入・試着操作を残したまま ID をコピーできます。
- アクセス可能なリソースを必要なときに読み込み、オブジェクトツリー、読み取り専用プロパティ、参照先への移動、検索、コピー、ファイル出力を利用できます。
- XML、JSON、RBXM モデルと LZ4・Zstandard 圧縮に対応し、対応形式の画像・音声・動画をプレビューできます。

アクセス権は Roblox に従い、ファイルを実行せずに調べます。読み込み上限は 32 MB、モデル 5,000 インスタンス、展開後のバイナリーブロック 128 MB です。テキストプレビューは最大 131,072 文字で、コピーとテキスト出力では取得できた全文を保持します。

### ⏱️ プレイ時間、メモ、フィード、通貨

- **プレイ時間：** アカウント別の推定時間、ホームの概要、検索可能な履歴、JSON 出力を利用できます。設定で記録を一時停止できます。ブラウザー動作中の Roblox の状態から推定するため、過去のセッションやブラウザー終了中の時間は復元できません。
- **ゲームメモ：** ゲームページごとに最大 5,000 文字の個人用メモを自動保存します。このブラウザー内の Roblox アカウントで共有され、Roblox には投稿されません。
- **ソーシャルフィード：** 対応するゲーム、コミュニティ、プロフィールページに X と YouTube のパネルを表示し、ページ種類ごとに切り替えられます。
- **Robux 換算：** Roblox と Creator Hub に通貨換算の目安を表示します。実際の決済価格とは異なる場合があります。

<a id="languages"></a>

## 🌐 対応言語

すべてのページ拡張機能は、**英語、簡体字中国語、繁体字中国語、インドネシア語、日本語、タイ語、韓国語**に対応しています。

**言語とデータ → 拡張機能の言語**で表示言語を選ぶか、**自動**で Roblox に合わせられます。`/ja/`、`/th/`、`/ko/` などの言語別パスにも対応します。

Roblox がほかの言語の場合はフォールバックモードになり、標準の配置を維持しながら画像・GIF 背景、カスタムカラー、フォントを利用できます。すべての機能を使うには **Roblox のウェブサイト言語**を対応言語に変更してください。拡張機能の言語だけを変えてもフォールバックモードは終了しません。

<a id="data-and-backups"></a>

## 💾 データとバックアップ

設定と保存内容はこのブラウザーに保存されます。Roblox データ、フィード、為替レート、サーバー地域を取得する機能は、[プライバシーポリシー](PRIVACY.ja.md)に記載された外部サービスに接続します。

| データ | 保存範囲 | 設定の完全バックアップ |
| --- | --- | --- |
| 設定、背景ファイル、フォントファイル | このブラウザー | 含む |
| ピン留めしたゲームとフォルダー | このブラウザー内の Roblox アカウントで共有 | 含む |
| ピン留めしたフレンド | Roblox アカウント別 | 含む |
| プレイ時間履歴 | Roblox アカウント別 | 保存済み履歴を含む |
| ゲームメモ | このブラウザー内の Roblox アカウントで共有 | 含む |
| 最近のサーバー | Roblox アカウント別 | 含まない |
| 使用中のサーバーフィルター | 現在のページのみ | 含まない |

最近使用した最大 10 アカウントについて、ゲームごとに最大 6 サーバーを記録します。公開されていないサーバー ID は復元できません。

**言語とデータ → バックアップと復元**で完全バックアップを出力・読み込みできます。**インポートは既存の拡張機能データを置き換えます。** リセットやブラウザーの移行前にエクスポートしてください。

**すべてリセット**はメモや最近のサーバー履歴を含む保存データと、対応するサイトキャッシュを削除します。利用規約への同意は保持されます。アンインストール前に保存データを削除する場合は、拡張機能がインストールされている間にリセットしてください。

詳しくは[プライバシーポリシー](PRIVACY.ja.md)と[利用規約](TERMS.ja.md)をご覧ください。拡張機能内のリンクは、表示言語に合った GitHub 上の公開文書を開きます。

<a id="troubleshooting-and-feedback"></a>

## 🛠️ トラブルシューティングとフィードバック

- **更新が反映されない：** 手動インストールでは `chrome://extensions` または `edge://extensions` から拡張機能を再読み込みし、その後 Roblox を再読み込みしてください。ページの再読み込みだけでは manifest やバックグラウンドの変更が読み込まれない場合があります。
- **一部の機能が表示されない：** Roblox のウェブサイト言語が対応一覧にあるか確認してください。API に依存する機能は一時的に利用できないこともあります。
- **要素が重なる・ページの動作がおかしい：** ほかの拡張機能が同じ要素を変更している場合があります。互換性通知は一部の既知の Roblox 拡張機能を識別します。原因を調べる際に重複する機能を調整してください。通知自体がほかの拡張機能を無効にすることはありません。
- **データを読み込めない：** Roblox や外部サービスの復旧後に再試行してください。API が返さないサーバー情報の補完や、リソースのアクセス権の回避はできません。

サポートは [lunar@lunarfox.my](mailto:lunar@lunarfox.my) までご連絡ください。対象ページの URL、ブラウザーとバージョン、Roblox の言語、再現手順、スクリーンショットを添えてください。

<a id="development"></a>

## 🧑‍💻 開発

インストールにはリポジトリ内のファイルをそのまま使用します。開発とテストには Node.js を使用します。

**更新のお知らせの編集：** 英語は[UPDATE.md](UPDATE.md)、日本語は[UPDATE.ja.md](UPDATE.ja.md)、ほかの言語は`UPDATE.zh-CN.md`、`UPDATE.zh-TW.md`、`UPDATE.id.md`、`UPDATE.th.md`、`UPDATE.ko.md`で個別に編集します。現在の拡張機能の言語に対応するファイルを読み込み、言語を切り替えると本文も更新します。翻訳がない場合や形式が不正な場合は英語を表示します。各翻訳の`id`を揃えると、言語を変えても既読のお知らせは再表示されません。文面の修正ではIDを維持し、新しいお知らせでは全翻訳を新しいID（例：`1.2.1`）に更新してください。`enabled: false`はその言語のみを無効にし、英語への切り替えも行いません。ビルドは不要で、拡張機能とRobloxページを再読み込みしてください。設定の下部の**更新のお知らせ**から再表示できます。

ソースを編集したら、対応する生成ファイルを更新してください。

| 変更したソース | コマンド |
| --- | --- |
| バックグラウンドモジュールとバンドル対象の依存関係 | `node scripts/build-service-worker.cjs` |
| ページブリッジ、ルート、互換性、サーバーカード、標準フレンド用ヘルパー | `node scripts/build-page-bridge.cjs` |
| `src/legal/content.json` のポリシー本文 | `node scripts/build-legal-docs.cjs` |

バンドルを確認し、パッケージ、ラベル、バックアップのチェックを実行します。

```sh
node scripts/build-service-worker.cjs --check
node scripts/build-page-bridge.cjs --check
node --test tests/extension-package.test.cjs tests/native-labels.test.cjs tests/backup.test.cjs
```

ブラウザーテストは独立したプロファイルとローカルの模擬ページを使います。`CHROME_BIN` に Chrome または Chromium の実行ファイルを指定してください。実際の拡張機能注入テストでは、さらに `CHROME_EXTENSION_TESTS=1`、未パッケージ拡張機能を読み込める Chrome for Testing または Chromium、Roblox の React バンドルのローカルコピーを指す `SERVER_VIEW_REACT_BUNDLE` が必要です。

```sh
node --test tests/extension-server-metadata-browser.test.cjs
```

リソースエクスプローラーのプロパティと列挙型の参照データは `node scripts/build-model-schema.cjs` で更新できます。
