<a id="installation"></a>

## 📦 安裝

從 [Chrome 線上應用程式商店](https://chromewebstore.google.com/detail/roblox-customizer/docflecekjjcekdcapolmneiomimiboi)安裝後，重新整理已開啟的 Roblox 頁面。

<details>
<summary><strong>在 Chrome 或 Edge 中手動載入儲存庫</strong></summary>

1. 下載或複製此儲存庫；若下載的是 ZIP 檔案，請先解壓縮。
2. 開啟 `chrome://extensions` 或 `edge://extensions`，啟用 **開發人員模式**。
3. 按一下 **載入未封裝項目**，選取包含 `manifest.json` 的資料夾。
4. 重新整理 Roblox。

儲存庫已包含執行擴充功能所需的檔案，安裝時無須建置。請將擴充功能資料夾保留在固定位置。

手動更新時，取代檔案後，在擴充功能管理頁按一下 **重新載入**，再重新整理 Roblox。

</details>

首次造訪時，擴充功能會提示你接受服務條款。此瀏覽器會記住接受狀態，即使使用 **重設全部** 也會保留。

首次進入 Roblox 網頁時，導覽會在語言和擴充功能相容性提示結束後自動顯示，介紹兩種設定入口：**Roblox 齒輪 → Roblox Customizer**，或點擊**瀏覽器工具列的 Roblox Customizer 圖示**，並提供 **開啟設定** 按鈕。更新公告接在導覽之後顯示，都不需要先開啟擴充功能設定。導覽和公告分別記住關閉狀態；新公告編號只會重新顯示公告。

<a id="quick-start"></a>

## 🚀 快速開始

開啟 Roblox 後，按一下瀏覽器工具列中的擴充功能圖示，或從 Roblox 齒輪選單開啟 **Roblox 自訂工具**。設定會自動儲存。

| 設定分類 | 可管理的內容 |
| --- | --- |
| **外觀** | 背景檔案、暗度、毛玻璃模糊與不透明度、透明效果、自訂配色及網頁字型。 |
| **首頁** | 首頁橫幅、問候語、時鐘、好友列數、推薦內容、遊戲時間與最近伺服器記錄。 |
| **釘選遊戲** | 啟用或停用釘選功能，查看已儲存的遊戲與資料夾。 |
| **社群** | 分別為遊戲、社群及個人檔案頁面啟用 X 與 YouTube 動態。 |
| **貨幣** | Robux 價值估算與顯示貨幣。 |
| **語言與資料** | 擴充功能語言、備份、還原及重設。 |

釘選遊戲時，在遊戲頁面按一下 **釘選遊戲** 並選取資料夾。置頂好友時，可在對方個人檔案按一下 **置頂好友**，或從首頁、自己的好友頁面開啟 **管理置頂好友**。

在 **首頁 → 首頁好友** 中，可分別開關 **顯示原版好友清單** 和 **顯示置頂好友**。關閉只會隱藏首頁區塊，保留置頂清單，重新整理後仍會記住選擇。

在 **首頁 → 首頁橫幅** 中關閉 **顯示橫幅背景框**，可移除最外層的毛玻璃背景與邊框，同時保留頭像、問候語、時鐘和遊戲時間卡片。選擇會自動儲存。

<a id="features"></a>

## ✨ 功能介紹

### 🎨 外觀與首頁

- 使用本機圖片、動態 GIF 或 MP4 影片作為背景，調整適應方式與暗度。
- 調整毛玻璃的模糊程度與不透明度，也可關閉模糊和透明效果。實驗性配色支援自訂文字、背景與強調色。
- 載入 TTF、OTF、WOFF 或 WOFF2 本機字型檔案，最大 32 MB。可預覽、暫時停用或還原預設字型；缺少的字元會使用備用字型。
- 自訂首頁問候語與時鐘，分別控制整條橫幅、虛擬人偶圖片、名稱、問候語、時間、日期及最常玩遊戲卡片的顯示。
- 將原版好友清單展開為最多三列，在首頁集中顯示置頂好友，並用資料夾整理釘選遊戲。
- 控制最愛、精選遊戲及推薦區域的顯示，或個別隱藏不想看到的推薦遊戲。

### 👥 好友與追蹤者

好友工具在 Roblox 原版工具列與卡片上增加功能，保留原有的虛擬人偶圖片、選單、聊天、加入遊戲與分頁。

- 依在線、遊戲中、離線、Studio 或置頂狀態篩選好友，支援依顯示名稱、使用者名稱、在線優先及置頂優先排序。
- 在原版卡片上勾選使用者，翻頁後仍保留選取；也可選取目前頁面或全部篩選結果。
- 批次解除好友關係、取消追蹤、接受或忽略好友請求。提交前會顯示所選名單；執行時顯示進度與失敗結果，可在目前操作結束後停止後續處理。
- 從好友個人檔案、原版好友清單或置頂好友管理視窗直接置頂、取消置頂。置頂記錄在目前瀏覽器中依 Roblox 帳號分別儲存。
- Roblox 計數 API 可用時，在原版追蹤者標題中顯示完整總數，取代 `500+` 的上限顯示。

解除好友關係會修改 Roblox 帳號中的關係，擴充功能無法復原。置頂只調整本機首頁清單。

### 🎮 遊戲與伺服器

- 在遊戲頁面查看徽章、通行證資訊及私人伺服器卡片，並使用 **遊戲備註** 面板。
- 依人數範圍、未滿狀態、國家、城市及 Ping 搜尋公共伺服器，支援連線排序、隨機排序、隨機加入及城市偏好備援。
- 在互動地球儀上拖曳、縮放、點選國家，或搜尋國家名稱來選擇地區。
- 資料可用時顯示伺服器效能、Roblox 提供的語言符合人數及執行中的場景發布版本。語言符合資訊跟隨 Roblox 網頁語言，不代表已確認玩家實際使用的語言。
- 重新加入最近的伺服器、檢查可用性，或清空某個遊戲的記錄。子場景記錄歸入所屬遊戲；在 **首頁 → 最近的伺服器** 中單獨控制記錄，不受遊戲時間開關影響。

伺服器篩選條件會在重新整理或切換頁面後重設。地區與數量取決於已載入的資料；新舊排序需要可靠的啟動時間。最近伺服器的可用性檢查最多掃描 500 個公共伺服器，結果不完整時保留為無法確認。已滿、關閉或受限制的伺服器可能拒絕加入。

### 🧍 虛擬人偶與動畫預覽

- 並排使用 Roblox 原生 3D 虛擬人偶預覽及獨立的 2D 預覽，分類與物品清單適應不同螢幕尺寸。
- 在 **我的虛擬人偶** 頁面展開 **虛擬人偶工具**，為六個身體部位設定 RGB 顏色，或在 Roblox 允許的範圍內調整受支援的已穿戴飾品的位置、旋轉及縮放。
- 編輯時先在本機預覽，按一下 **套用顏色** 或 **套用飾品調整** 後才會修改目前登入的虛擬人偶。重新整理頁面可更新 Roblox 原生預覽。
- 在動畫套裝、單個動畫及表情商品頁按一下 **在我的模型上預覽**，即可保留目前飾品並播放動作；原版動作選擇與播放控制保持同步。

動畫預覽使用 R15 模型，在本機執行，捲出螢幕或切到背景分頁時暫停。預覽動畫不會更改目前穿戴或儲存造型。

### 🧰 物品詳情與資源瀏覽器

- 在目錄、套裝、資源庫及創作者商店的原版物品詳情中補充 ID、可取得的日期及銷售或數量資料。支援複製 ID，保留原有購買與試穿控制項。
- 按需載入可存取的資源，瀏覽物件樹、查看唯讀屬性、跳轉參照、搜尋、複製內容及匯出檔案。
- 支援 XML、JSON、RBXM 模型及 LZ4、Zstandard 壓縮，並可預覽支援的圖片、音訊與影片。

資源存取遵循 Roblox 權限，查看時不會執行檔案。載入上限為 32 MB、5,000 個模型物件及 128 MB 的展開二進位區塊。文字預覽最多顯示 131,072 個字元；複製與文字匯出保留可取得的完整值。

### ⏱️ 遊戲時間、備註、動態與貨幣

- **遊戲時間：** 依帳號估算，提供首頁摘要、可搜尋的歷史記錄與 JSON 匯出，可在設定中暫停。時間根據瀏覽器執行期間的 Roblox 狀態估算，無法補記過去的遊玩或瀏覽器關閉期間的時間。
- **遊戲備註：** 每個遊戲頁面可儲存最多 5,000 個字元的私人備註，輸入後自動儲存。目前瀏覽器內的 Roblox 帳號共用備註，內容不會發布到 Roblox。
- **社群動態：** 在受支援的遊戲、社群及個人檔案頁面顯示 X 與 YouTube 動態，並依頁面類型分別開關。
- **Robux 估算：** 在 Roblox 與 Creator Hub 顯示貨幣價值參考，實際結帳價格可能不同。

<a id="languages"></a>

## 🌐 語言支援

完整頁面增強支援 **英語、簡體中文、繁體中文、印尼語、日語、泰語與韓語**。

在 **語言與資料 → 擴充功能語言** 中選取介面語言，或使用 **自動** 跟隨 Roblox。支援 `/ja/`、`/th/`、`/ko/` 等本地化頁面路徑。

Roblox 使用其他語言時，擴充功能會進入備援模式：保留圖片／GIF 背景、自訂配色與字型，並保持原生版面配置。將 **Roblox 網頁語言** 改為受支援的語言即可恢復完整功能；僅更改擴充功能介面語言不會離開備援模式。

<a id="data-and-backups"></a>

## 💾 資料與備份

設定與儲存的內容保留在目前瀏覽器。讀取 Roblox 資料、動態、匯率或伺服器地區的功能會連線至對應服務，詳見[隱私權政策](PRIVACY.zh-TW.md)。

| 資料 | 儲存範圍 | 完整設定備份 |
| --- | --- | --- |
| 設定、背景檔案與字型檔案 | 目前瀏覽器 | 包含 |
| 釘選遊戲與資料夾 | 目前瀏覽器內的 Roblox 帳號共用 | 包含 |
| 置頂好友 | 各 Roblox 帳號分別儲存 | 包含 |
| 遊戲時間 | 各 Roblox 帳號分別儲存 | 包含已儲存的歷史記錄 |
| 遊戲備註 | 目前瀏覽器內的 Roblox 帳號共用 | 包含 |
| 最近伺服器 | 各 Roblox 帳號分別儲存 | 不包含 |
| 目前伺服器篩選條件 | 僅目前頁面 | 不包含 |

最近伺服器為最近使用的十個帳號分別記錄，每個遊戲最多保留六個伺服器。無法恢復 Roblox 未提供的伺服器 ID。

在 **語言與資料 → 備份與還原** 中匯出或匯入完整備份。**匯入會取代現有擴充功能資料。** 重設或移轉至其他瀏覽器前，請先匯出備份。

**重設全部** 會刪除已儲存的擴充功能資料，包括備註與最近伺服器記錄，並清理受支援的網站快取；服務條款接受狀態會保留。若要在解除安裝前刪除儲存的資料，請在擴充功能仍安裝時執行重設。

更多說明見[隱私權政策](PRIVACY.zh-TW.md)與[服務條款](TERMS.zh-TW.md)。擴充功能內的政策連結會依介面語言開啟 GitHub 上已發布的文件。

<a id="troubleshooting-and-feedback"></a>

## 🛠️ 問題排查與回饋

- **更新後沒有變化：** 手動安裝時，先在 `chrome://extensions` 或 `edge://extensions` 中重新載入擴充功能，再重新整理 Roblox。只重新整理網頁可能無法載入 manifest 或背景指令碼的更新。
- **部分增強功能未顯示：** 檢查 Roblox 網頁語言是否在上述支援清單中；依賴 API 的功能也可能暫時無法使用。
- **元素重疊或頁面行為異常：** 其他擴充功能可能修改同一處元素。相容性提醒可辨識部分已知 Roblox 擴充功能；排查時可視需要調整重複功能，提醒本身不會停用其他擴充功能。
- **資料載入失敗：** Roblox 或外部服務恢復後可重試。擴充功能無法補充 API 未提供的伺服器欄位，也無法繞過資源存取權限。

需要協助時，請寄信至 [lunar@lunarfox.my](mailto:lunar@lunarfox.my)，附上受影響的頁面連結、瀏覽器及版本、Roblox 語言、重現步驟與螢幕截圖。

<a id="development"></a>

## 🧑‍💻 開發說明

安裝可直接使用儲存庫中的檔案。開發與測試需要 Node.js。

**編輯更新公告：** 英文儲存在 [UPDATE.md](UPDATE.md)，繁體中文儲存在 [UPDATE.zh-TW.md](UPDATE.zh-TW.md)，其他語言分別使用 `UPDATE.zh-CN.md`、`UPDATE.id.md`、`UPDATE.ja.md`、`UPDATE.th.md`、`UPDATE.ko.md`，可獨立編輯。彈窗依擴充功能目前語言讀取，切換語言時更新內文；對應檔案缺失或格式錯誤時回退至英文。各語言保持相同 `id`，避免切換語言重複彈出。修正文案時保留編號，發布新公告時將各語言統一改為新編號（如 `1.2.1`）。`enabled: false` 只停用該語言公告，不回退至英文。無需打包，重新載入擴充功能並重新整理 Roblox 即可。使用者也可從設定底部的 **更新公告** 隨時重看。

修改原始碼後，重新產生對應檔案：

| 修改內容 | 命令 |
| --- | --- |
| 背景模組及其封裝相依項目 | `node scripts/build-service-worker.cjs` |
| 網頁橋接、路徑工具、相容檢查、伺服器卡片或原版好友適配指令碼 | `node scripts/build-page-bridge.cjs` |
| `src/legal/content.json` 中的政策文字 | `node scripts/build-legal-docs.cjs` |

檢查指令碼套件，並執行擴充功能資源、文字辨識及備份的針對性檢查：

```sh
node scripts/build-service-worker.cjs --check
node scripts/build-page-bridge.cjs --check
node --test tests/extension-package.test.cjs tests/native-labels.test.cjs tests/backup.test.cjs
```

瀏覽器測試使用獨立設定檔與本機模擬頁面，執行前需將 `CHROME_BIN` 指向 Chrome 或 Chromium。實際擴充功能注入測試另需設定 `CHROME_EXTENSION_TESTS=1`，使用支援載入未封裝擴充功能的 Chrome for Testing 或 Chromium，並將 `SERVER_VIEW_REACT_BUNDLE` 指向 Roblox React 指令碼的本機副本：

```sh
node --test tests/extension-server-metadata-browser.test.cjs
```

資源瀏覽器的屬性與列舉參考資料可透過 `node scripts/build-model-schema.cjs` 更新。
