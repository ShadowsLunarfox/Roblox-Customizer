# Catatan Pembaruan

## Dukungan Bahasa Baru

1. Bahasa Indonesia
2. Bahasa Jepang
3. Bahasa Thai
4. Bahasa Korea

## Perubahan dan Perbaikan Bug

1. Memperbaiki masalah yang membuat pengguna tidak dapat mengubah warna kulit atau atribut lain di halaman Avatar.
2. Memperbaiki masalah pada fitur penyaringan server.
3. Memperbaiki masalah tampilan avatar di halaman toko Paket Animasi.
4. Memperbaiki berbagai masalah antarmuka pada sejumlah halaman.

## Fitur Baru

1. Menambahkan dukungan font web kustom.
2. Menambahkan banner Beranda yang dapat disesuaikan untuk menampilkan avatar, nama pengguna, jam, dan total waktu bermain. Setiap elemen dapat diaktifkan atau dinonaktifkan secara terpisah.
3. Menambahkan opsi untuk menonaktifkan fitur penyematan game.
4. Kini Anda dapat melihat parameter model item, tautan tekstur, dan pengaturan warna di halaman detail item dalam Toko.
5. Memperluas informasi server dengan versi server, metrik kinerja, dan bahasa yang didukung.
6. Menambahkan kemampuan untuk menandai teman sebagai favorit.
