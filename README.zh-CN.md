**💱 Robux 价值估算：** 在 Roblox 和 Creator Hub 显示货币价值参考，实际结算价格可能不同。

**📝 游戏备注：** 在游戏页面的“游戏备注”区域添加私人提醒或攻略，输入后自动保存，也可编辑和删除。每个游戏页面分别保存最多 5,000 个字符。备注仅存于当前浏览器，所有 Roblox 账号共用，不会发布到 Roblox；支持随设置备份导出、导入，并随“重置全部”删除。

服务器筛选条件仅在当前页面生效，刷新或切换页面后重置，不写入本地存储或设置备份。

地球拖动时使用缓存地图坐标的 Canvas 预览，松手后恢复精细且可点击的 SVG 边界。城市标记会重复利用，侧栏更新延后到拖动结束；筛选数据没有变化时，地球保持空闲，不持续重绘。

公共服务器卡片会在数据可用时显示以 60 FPS 为基准的服务器性能、Roblox 提供的语言匹配人数，以及该服务器运行的地图发布版本。语言匹配使用 Roblox 网页语言，不受插件界面语言影响，也不代表已确认玩家实际使用的语言。地图版本复用地区查询的服务器连接请求；地区已知时，仅查询版本，不再查询 IP 地理位置。额外加入信息请求会缓存、去重，同时最多执行两个。缺失字段不显示，保留原生加入按钮。

**↩️ 最近服务器：** 每个游戏的服务器标签页显示该游戏自己的记录，包括同一游戏的子场景。可以重新加入、检查可用性，或仅清空此游戏的列表。为最近使用的 10 个账号分别按游戏保留最多 6 个服务器，新增时只移除该游戏最旧的记录。设置中的 **主页 → 最近的服务器** 按游戏分组显示全部列表，并单独控制记录，不受游戏时长开关影响。

**好友工具：** 在 Roblox 原搜索栏旁补充状态筛选、排序和多选控件，在原好友卡片上增加复选框。列表、头像、菜单、聊天、加入游戏与分页继续使用 Roblox 原有组件和事件处理。支持按在线、游戏中、离线、Studio 或置顶状态筛选，以及名称、用户名、在线优先和置顶优先排序。多选可跨原分页保留，也可选择当前页或全部筛选结果，批量解除好友关系、取消关注、接受或忽略好友请求。关系变更前会显示所选名单，执行时显示进度，可在当前操作后停止；失败和未处理的用户保持选中。也可在好友个人主页的原版操作区域直接置顶或取消置顶，同步更新首页的置顶好友，并按 Roblox 账号分别保存。

**动画预览：** 动画套装、商城单个动画及表情商品页，并排显示原生播放器和可选的用户模型预览。点击 **在我的模型上预览** 即可加载当前模型并保留饰品，播放所选动作。套装动作选择与原生播放／暂停保持同步；单个移动动画按实际类型播放，表情动作直接应用于预览模型。也可以重置视角或重新加载模型。预览使用 R15 模型，在本地以最高 30 FPS 渲染，滚出屏幕或切到后台时暂停，不会更改当前穿戴或保存造型。渲染器、许可证与对应源码均随扩展打包，见[依赖说明](src/assets/animation-preview/vendor/README.md)。

**物品工具：** 在目录、套装、资源库和创作者商店的物品页，ID、可取得的日期及销售／数量数据直接补充到原有物品详情中；保留原有字段并避免重复，复制 ID 按钮放在 ID 旁边。预览和试穿使用原来的控件，详情下方提供创作者商店、刷新和导出操作。资源浏览器提供对象树与只读属性面板、模型／属性筛选、引用跳转、复制和文本查看，支持 XML、JSON，以及 LZ4／Zstandard 压缩的 RBXM，也可预览支持的图片、音频和视频。文件加载上限为 32 MB，最多浏览 5,000 个模型对象，二进制块展开上限为 128 MB。长文本预览最多显示 131,072 个字符，复制与文本导出保留可取得的完整值。不支持的属性类型会单独标明。资源文件不会被执行，访问权限由 Roblox 决定。

资源浏览器界面与模型读取器为独立实现。Zstandard 解压使用 [fzstd 0.1.1](https://github.com/101arrowz/fzstd)，遵循其 [MIT 许可证](src/assets/vendor/fzstd.LICENSE)。属性分类与枚举名称来自随扩展打包的 Roblox 官方 Studio API 数据，可运行 `node scripts/build-model-schema.cjs` 更新。未打包 BTRoblox 的主体代码或图标素材。

**头像工具：** 在 **我的头像** 页面展开 **头像工具**，可为六个身体部位选择完整 RGB 颜色，并调整受支持的已穿戴饰品的位置、旋转和缩放。范围以 Roblox 规则为准。预览编辑只在本地生效，点击 **应用颜色** 或 **应用饰品** 后才会修改当前登录的 Roblox 头像；刷新网页可更新 Roblox 原生预览。工具保留其他穿戴物品，不会购买物品。

## 📦 安装

[![从 Chrome 应用商店安装](icons/chrome-web-store-button.zh-CN.svg)](https://chromewebstore.google.com/detail/roblox-customizer/docflecekjjcekdcapolmneiomimiboi)

<details>
<summary><strong>🛠️ 在 Chrome 或 Edge 中手动安装</strong></summary>

从此仓库加载扩展：

1. 下载或克隆此仓库；如果下载的是 ZIP 文件，请先解压。
2. 打开 `chrome://extensions` 或 `edge://extensions`，启用 **开发者模式**。
3. 点击 **加载已解压的扩展程序**，选择包含 `manifest.json` 的文件夹。
4. 刷新 Roblox，点击浏览器工具栏中的扩展图标，或从 Roblox 齿轮菜单打开 **Roblox 自定义工具**。

安装时无需构建。请将扩展文件夹保留在固定位置。

</details>

> [!NOTE]
> 安装后首次访问 Roblox 网站时，会自动弹出服务条款提示。此浏览器会记住接受状态，即使使用 **重置全部** 也不会重复提示。

## 🚀 快速上手

- 在 **外观** 中选择背景，调整适应方式、暗度、模糊程度和不透明度。更改会自动保存。切回标签页时优先恢复动态壁纸，其他页面增强分批处理。恢复时会复用已读取的本地文件；视频卡住时会自动重建播放器，无需刷新整个网页。
- 在 **外观 → 网页字体** 中选择 TTF、OTF、WOFF 或 WOFF2 文件（最大 32 MB），即可预览并替换 Roblox 网页文字的字体，也可暂时停用或恢复默认字体。缺少的字符会使用备用字体。
- 在游戏页面点击 **置顶游戏**，选择文件夹并确认；在主页的 **置顶游戏** 区域管理文件夹。
- 在 **设置 → 置顶游戏** 关闭 **启用置顶游戏**，即可关闭首页区域和游戏页面的置顶按钮。此设置栏中仍可查看已保存的游戏和文件夹。
- 打开游戏的 **服务器** 标签页，设置筛选条件后点击 **搜索**。
- 使用 **备份与恢复** 导出设置、背景、置顶游戏和时长记录。导入会替换现有扩展数据。

## 🌐 语言支持

完整功能要求 Roblox 使用 **英语、简体中文、繁体中文、印尼语、日语、泰语或韩语**。其他语言会进入回退模式：保留图片／GIF 背景、自定义颜色和自定义字体，并保持 Roblox 原生页面布局。

可在 **语言与数据 → 扩展语言** 选择 **日本語**，也可使用“自动”跟随 Roblox 的日语设置。支持 `/ja/` 与 `/ja-jp/` 路径的日语页面。

选择 **ไทย** 可使用泰语，也可使用“自动”跟随 Roblox 的泰语设置。支持 `/th/` 与 `/th-th/` 路径的泰语页面。

选择 **한국어** 可使用韩语，也可使用“自动”跟随 Roblox 的韩语设置。支持 `/ko/` 与 `/ko-kr/` 路径的韩语页面。

切换 Roblox 的语言即可恢复完整功能。仅更改扩展的界面语言不会退出回退模式。

## 💾 数据与使用限制

检测到 BTRoblox、RoPro、RoGold、RoSeal 等已知 Roblox 插件的页面标记或可识别的插件资源地址时，会弹出兼容性提醒，说明大范围调整 Roblox 官网界面可能与其他插件的修改相互影响，造成控件重复、元素重叠或显示与加载异常。用户可以继续同时使用多个插件，无需二选一；出现问题时，按需调整重复功能只是可选的排查方式。点击 **我已了解，继续使用 Roblox** 后，相同插件不会反复提醒；检测到新的插件时可再次提醒。检测和提醒记录仅在本地处理，无法列出所有已安装插件，也不会禁用或更改其他插件。

设置、背景、置顶游戏和时长记录保存在当前浏览器本地。游戏时长根据浏览器运行期间的 Roblox 状态估算，无法补记过去的会话或浏览器关闭期间的时间。

最近服务器根据浏览器运行期间已确认的 Roblox 状态记录，无法获取被隐藏的服务器 ID。重新加入会打开 Roblox，已满、已关闭或受限制的服务器可能拒绝加入。可用性检查最多扫描 500 个公共服务器，结果不完整时显示无法确认。完整备份不包含最近服务器记录；重置全部会清除已保存的服务器记录。

服务器数据、社交动态和汇率依赖 Roblox 及外部服务，暂时不可用时可稍后重试。卸载前请导出备份，并使用 **重置全部** 一并删除已保存的背景和网站缓存。

请阅读 GitHub 上已发布的[隐私政策](https://github.com/ShadowsLunarfox/Roblox-Customizer/blob/main/PRIVACY.zh-CN.md)和[服务条款](https://github.com/ShadowsLunarfox/Roblox-Customizer/blob/main/TERMS.zh-CN.md)。设置菜单及首次访问提示会打开与扩展语言对应的版本。如需支持或咨询隐私问题，请联系 [lunar@lunarfox.my](mailto:lunar@lunarfox.my)。

## 💬 更新与反馈

替换扩展文件后，重新加载扩展并刷新 Roblox。反馈问题时，请提供页面链接、浏览器版本、复现步骤和截图。

<details>
<summary><strong>🔧 参与扩展开发？</strong></summary>

修改后台脚本后，请运行 `node scripts/build-service-worker.cjs` 更新仓库中的后台脚本包。
修改网页桥接、路径工具、语言兼容检查或服务器卡片脚本后，请运行 `node scripts/build-page-bridge.cjs`。MAIN 环境的入口需自行包含依赖，避免 Chrome 对不同脚本环境中的同名文件去重后缺少依赖。

真实扩展注入回归测试为 `node --test tests/extension-server-metadata-browser.test.cjs`。需设置 `CHROME_EXTENSION_TESTS=1`，将 `CHROME_BIN` 指向 Chrome for Testing 或 Chromium，并将 `SERVER_VIEW_REACT_BUNDLE` 指向 Roblox React 脚本的本地副本。测试使用独立配置、实际 manifest 和本地模拟接口。

</details>

扩展链接到 GitHub `main` 分支上的政策 Markdown 文件。已发布的政策更新可直接在 GitHub 阅读，无需更新扩展。
