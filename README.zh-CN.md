## 📦 安装

[![从 Chrome 应用商店安装](icons/chrome-web-store-button.zh-CN.svg)](https://chromewebstore.google.com/detail/roblox-customizer/docflecekjjcekdcapolmneiomimiboi)

<details>
<summary><strong>🛠️ 在 Chrome 或 Edge 中手动安装</strong></summary>

从此仓库加载扩展：

1. 下载或克隆此仓库；如果下载的是 ZIP 文件，请先解压。
2. 打开 `chrome://extensions` 或 `edge://extensions`，启用 **开发者模式**。
3. 点击 **加载已解压的扩展程序**，选择包含 `manifest.json` 的文件夹。
4. 刷新 Roblox，点击浏览器工具栏中的扩展图标，或从 Roblox 齿轮菜单打开 **Roblox 自定义工具**。

安装时无需构建。请将扩展文件夹保留在固定位置。

</details>

> [!NOTE]
> 安装后首次访问 Roblox 网站时，会自动弹出服务条款提示。此浏览器会记住接受状态，即使使用 **重置全部** 也不会重复提示。

## 🚀 快速上手

- 在 **外观** 中选择背景，调整适应方式、暗度、模糊程度和不透明度。更改会自动保存。
- 在 **外观 → 网页字体** 中选择 TTF、OTF、WOFF 或 WOFF2 文件（最大 32 MB），即可预览并替换 Roblox 网页文字的字体，也可暂时停用或恢复默认字体。缺少的字符会使用备用字体。
- 在游戏页面点击 **置顶游戏**，选择文件夹并确认；在主页的 **置顶游戏** 区域管理文件夹。
- 在 **设置 → 置顶游戏** 关闭 **启用置顶游戏**，即可关闭首页区域和游戏页面的置顶按钮。此设置栏中仍可查看已保存的游戏和文件夹。
- 打开游戏的 **服务器** 标签页，设置筛选条件后点击 **搜索**。
- 使用 **备份与恢复** 导出设置、背景、置顶游戏和时长记录。导入会替换现有扩展数据。

## 🌐 语言支持

完整功能要求 Roblox 使用 **英语、简体中文、繁体中文、印尼语、日语、泰语或韩语**。其他语言会进入回退模式：保留图片／GIF 背景、自定义颜色和自定义字体，并保持 Roblox 原生页面布局。

可在 **语言与数据 → 扩展语言** 选择 **日本語**，也可使用“自动”跟随 Roblox 的日语设置。支持 `/ja/` 与 `/ja-jp/` 路径的日语页面。

选择 **ไทย** 可使用泰语，也可使用“自动”跟随 Roblox 的泰语设置。支持 `/th/` 与 `/th-th/` 路径的泰语页面。

选择 **한국어** 可使用韩语，也可使用“自动”跟随 Roblox 的韩语设置。支持 `/ko/` 与 `/ko-kr/` 路径的韩语页面。

切换 Roblox 的语言即可恢复完整功能。仅更改扩展的界面语言不会退出回退模式。

## 💾 数据与使用限制

设置、背景、置顶游戏和时长记录保存在当前浏览器本地。游戏时长根据浏览器运行期间的 Roblox 状态估算，无法补记过去的会话或浏览器关闭期间的时间。

最近服务器根据浏览器运行期间已确认的 Roblox 状态记录，无法获取被隐藏的服务器 ID。重新加入会打开 Roblox，已满、已关闭或受限制的服务器可能拒绝加入。可用性检查最多扫描 500 个公共服务器，结果不完整时显示无法确认。完整备份不包含最近服务器记录；重置全部会清除已保存的服务器记录。

服务器数据、社交动态和汇率依赖 Roblox 及外部服务，暂时不可用时可稍后重试。卸载前请导出备份，并使用 **重置全部** 一并删除已保存的背景和网站缓存。

请阅读 GitHub 上已发布的[隐私政策](https://github.com/ShadowsLunarfox/Roblox-Customizer/blob/main/PRIVACY.zh-CN.md)和[服务条款](https://github.com/ShadowsLunarfox/Roblox-Customizer/blob/main/TERMS.zh-CN.md)。设置菜单及首次访问提示会打开与扩展语言对应的版本。如需支持或咨询隐私问题，请联系 [lunar@lunarfox.my](mailto:lunar@lunarfox.my)。

## 💬 更新与反馈

替换扩展文件后，重新加载扩展并刷新 Roblox。反馈问题时，请提供页面链接、浏览器版本、复现步骤和截图。

<details>
<summary><strong>🔧 参与扩展开发？</strong></summary>

修改后台脚本后，请运行 `node scripts/build-service-worker.cjs` 更新仓库中的后台脚本包。
修改网页桥接、路径工具、语言兼容检查或服务器卡片脚本后，请运行 `node scripts/build-page-bridge.cjs`。MAIN 环境的入口需自行包含依赖，避免 Chrome 对不同脚本环境中的同名文件去重后缺少依赖。

真实扩展注入回归测试为 `node --test tests/extension-server-metadata-browser.test.cjs`。需设置 `CHROME_EXTENSION_TESTS=1`，将 `CHROME_BIN` 指向 Chrome for Testing 或 Chromium，并将 `SERVER_VIEW_REACT_BUNDLE` 指向 Roblox React 脚本的本地副本。测试使用独立配置、实际 manifest 和本地模拟接口。

</details>
